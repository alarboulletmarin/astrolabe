# Journal

Every activity, week by week, in a table that takes the whole width.

<!-- screenshot: the Journal, a few weeks, with the altitude profile column -->

## Reading it

Each week has a heading, "Week of …", with its totals: number of outings, time, and the kilometres sport by sport. Kilometres are never added up across sports.

Each row is an outing: its date, its name, then the columns you chose.

## Search and filter

- **Search**: the field "Search an outing" matches the name and the sport.
- **Sport**: the chips filter by sport. **All** shows every sport.
- With nothing found, the page says "No outing matches."

## Columns

The **Columns** button lists the columns to show or hide. Your choice is kept.

| Column | Shows |
|---|---|
| Distance | the distance |
| Time | the duration |
| Pace | pace, speed or time per 100 m, depending on the sport |
| Gap | the gap to your usual pace on like outings, `≈ usual` when it is small |
| Gain | the elevation gained |
| Gain / km | metres of climb per kilometre: how steep the outing is |
| HR | the average heart rate |
| Calories | the calories burned |
| Rank | the place among outings of the same sport, by distance |
| HR zones | the time in each heart rate zone, against your maximum heart rate (see [Form](form.md)) |
| Profile | the altitude along the outing, once its file is read |

Columns that do not fit fold away as the window narrows, the least useful first. The altitude profile takes what the row has left.

## Opening an activity

A click on a row, or `Enter` on the selected one, opens the [activity](activity.md). `↑` and `↓` move the selection.

## Without data

Before the first synchronisation the page reads "Nothing here yet." with a button **Add my key** that leads to the [settings](settings.md).
